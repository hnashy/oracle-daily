# ORACLE Daily

تطبيق تنبؤ وتحليل كرة القدم باستخدام Ensemble من Elo وDixon–Coles.

## التحسينات الحالية

- Elo ثلاثي النتائج: فوز محلي / تعادل / فوز ضيف.
- وزن متحرك محافظ بين Elo وDixon–Coles باستخدام Brier وLog Loss.
- Form مبني على آخر 5 مباريات لكل فريق قبل وقت المباراة.
- ترتيب الدوري محسوب من المباريات المنتهية قبل وقت المباراة فقط.
- آخر 5 مواجهات مباشرة H2H، مع تجاهل الإشارة عند قلة المواجهات.
- اختبار Walk-Forward لمنع تسرب النتائج المستقبلية.

## تشغيل محلي

افتح `index.html` عبر خادم محلي، لأن مصدر OpenFootball يعتمد على طلبات الشبكة:

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## OddsHarvester

يوجد مصدر OpenFootball للنتائج التاريخية، لكن ربط OddsHarvester يحتاج endpoint ومفتاح API وتوثيق الحقول. لا تُحفظ المفاتيح داخل `index.html`؛ يجب استخدام proxy آمن أو موصل خادم.

## تنبيه

المشروع بحثي واحتمالي. لا توجد نتائج مضمونة ولا توصية مالية أو رهان شخصي.

## منطق السياق الجديد

لكل مباراة مستقبلية، لا تُستخدم إلا البيانات ذات `ts` الأقدم من وقت المباراة:

- آخر 5 مباريات لكل فريق: النتائج والنقاط وفارق الأهداف.
- ترتيب الموسم قبل المباراة: النقاط، فارق الأهداف، والترتيب.
- آخر 5 مواجهات مباشرة: بإضمحلال زمني، ولا تُستخدم الإشارة إذا كانت أقل من 3 مواجهات.
- تعديل محافظ على احتمالات Elo فقط؛ Dixon–Coles يبقى قائمًا على توزيع الأهداف.
- احتمال التعادل محفوظ صراحةً في Elo ولا يُجبر النموذج على اختيار فوز محلي أو فوز ضيف فقط.

## الاختبار

```bash
node backtest.js
```

الاختبار Walk-Forward ويحسب Brier وLog Loss والمعيار المركب، مع تحديث الحالة بعد النتيجة فقط.
